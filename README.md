# YouTube Downloader

Aplicativo com interface gráfica para baixar vídeos do YouTube.

## Recursos

- Colar o link do vídeo;
- Baixar em MP4;
- Baixar somente o áudio em MP3;
- Escolher a pasta de destino;
- Exibir o progresso do download;
- Interface moderna.

## Instalação

Instale as dependências:

```bash
pip install -r requirements.txt
